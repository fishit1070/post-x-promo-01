This entry promotes make.fun's "make your own bounty" feature. The linked X post by @Fiqkenstein quotes the official @makefunai announcement, carries an original photo, and invites bounty ideas from readers. The program itself stays simple: it hands the post's URL to the grader by copying POST.json to the output directory.

## Run it

```sh
MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=./output node main.ts
```
